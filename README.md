# Math Quiz Game (C++) 🧮

## 📝 Description
This is a functional Math Quiz game developed as part of the **Programming Advices (Level 2)** curriculum. The project demonstrates the ability to manage game logic, user input validation, and dynamic question generation based on user preferences.

## 🚀 Features
- **Difficulty Levels:** Choose between Easy, Med, Hard, or Mixed levels.
- **Operation Types:** Practice Addition, Subtraction, Multiplication, Division, or Mixed operations.
- **Dynamic Quiz:** Generates a specific number of questions based on user input.
- **Performance Summary:** Displays final results with screen color feedback (Green for Pass / Red for Fail).

## 🛠️ Technologies Used
- **Language:** C++
- **Concepts:** Enums, Structs, Random Number Generation, Loops, and Conditional Logic.

## 📖 How to Run
1. Clone the repository.
2. Compile the `main.cpp` file using a C++ compiler (like GCC or Visual Studio).
3. Run the generated executable.
